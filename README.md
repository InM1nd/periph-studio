# Periph Studio

Настройка клавиатур и мышей разных производителей в одном приложении (раньше — NJ80 Studio).

## Интерфейс

Тёмная тема Black Studio: устройства слева, доступные функции выбранного устройства во вкладках сверху.
Окно использует фирменную чёрную шапку и иконку P. Шапка поддерживает перетаскивание,
двойной щелчок для разворачивания и штатные кнопки Windows, включая Snap Layouts на Windows 11.
Знак в шапке следует выбранному акценту; иконки окна, панели задач и EXE созданы из `icon.svg`.
В разделе **Настройки → Акцентный цвет** можно выбрать готовый оттенок, собственный цвет из палитры
или ввести HEX. Цвет применяется сразу и сохраняется на этом компьютере между запусками.
Кнопка **По умолчанию** возвращает синий акцент. Цвет интерфейса не меняет подсветку устройств.

На экране подсветки Keydous/NJ80 изменения сначала видны в предпросмотре. **Применить** записывает
их в устройство, **Отменить** возвращает последние прочитанные или применённые значения.
Кнопка **Все эффекты** раскрывает остальные доступные режимы. Для других устройств сохраняются
их собственные возможности и ограничения протокола.

Проверка настроек оформления: `npm test` (не требует подключённого устройства).

## Обновления из приложения

В **Настройки → Обновления** доступны проверка стабильного релиза на GitHub, загрузка portable-архива
с прогрессом и отменой и кнопка **Установить и перезапустить**. Проверка запускается вручную.
Перед открытием архив проверяется по SHA-256; незавершённые или повреждённые загрузки не принимаются.
Релизы загружаются только из `InM1nd/periph-studio`. При отсутствии релизов, сети или доступного
архива приложение показывает объяснение и позволяет повторить попытку.

Скачивание из приложения доступно в упакованной Windows x64 сборке. В режиме разработки можно
проверить релиз и открыть страницу GitHub. Архивы сохраняются в `%APPDATA%\Periph Studio\updates`.
После загрузки нажмите **Установить и перезапустить**. Новая версия распакуется и проверится автоматически,
приложение закроется, установщик заменит его папку и запустит обновлённый EXE по прежнему пути.
Если новая версия не подтвердит загрузку интерфейса, установщик восстановит предыдущую и запустит её.
Настройки и бэкапы остаются в `%APPDATA%\Periph Studio`, ярлыки продолжают указывать на прежний путь.
Резервная копия предыдущей версии остаётся рядом в `.periph-studio-backup-<идентификатор>`.

Сборку 0.5.0 нужно один раз распаковать целиком в отдельную папку: в старых сборках ещё нет установщика
и манифеста `.periph-studio-install.json`. Следующие версии с таким манифестом устанавливаются из приложения.
Папка программы должна быть доступна для записи и содержать только файлы приложения. При нехватке прав,
посторонних файлах или повреждении пакета подготовка остановится до закрытия приложения.
Кнопки **Открыть архив** и **Показать в папке** остаются доступны для ручной установки.

### Публикация следующей версии

1. Измените версию `X.Y.Z` в `package.json` и `package-lock.json`, закоммитьте изменения.
2. Создайте тег `vX.Y.Z` и отправьте его в GitHub вместе с кодом.
3. Workflow `.github/workflows/release.yml` запустит тесты, соберёт Windows portable и опубликует релиз
   с `Periph-Studio-X.Y.Z-Windows-x64.zip` и одноимённым `.zip.sha256`.

GitHub Actions должны быть включены, а workflow должен иметь право создавать релизы (`contents: write`).
Можно также выполнить `npm run zip` локально и вручную прикрепить эти два файла к стабильному релизу.
Исходники ZIP, автоматически добавляемые GitHub, не являются portable-сборкой. Тег должен совпадать
с версией приложения; черновики и предварительные версии для обновления не используются.

## Что поддерживается

| Семейство | Устройства | Что умеет | Статус |
|---|---|---|---|
| Keydous / Royuan | NJ80-AP (3151:4003) и 61 модель yc200 из таблицы драйвера Keydous | сведения, подсветка, частота опроса, Win-lock, WASD; раскладка — только NJ80 | NJ80 проверена; остальные yc200 — по описанию |
| Keydous / Royuan, другие классы | 112 моделей yzw и др. | только опознание | запись отключена |
| Winbond 0416:B23C | KT87, KT108, Pulsar PCMK… | подсветка клавиш и логотипа | KT87 проверена |
| Sonix / DriveAll | MSI Forge GK600 TKL Wireless (0DB0:EA47), Womier SK80, Xinmeng M87 Pro, Aula F98 Pro | подсветка: 21 режим, цвет, радуга, яркость, скорость | по описанию (протокол Womier SK80) |
| Logitech HID++ | мыши через Lightspeed / Unifying / Bolt и по кабелю, в т.ч. новые (Superlight 2, G502 X…) с расширенным DPI 0x2202 и частотой до 8000 Гц (0x8061) | заряд, DPI, частота опроса; встроенные профили переключаются в управление с ПК | PRO X Wireless проверена, Superlight 2 — на эмуляции |
| Razer | мыши Razer (протокол openrazer) | заряд, DPI, частота опроса (в т.ч. HyperPolling до 8000 Гц) | по описанию |
| QMK / VIA | клавиатуры с raw HID FF60 | сведения, подсветка RGB Matrix / RGB Light | по описанию протокола |

Неизвестное устройство: на вкладке «Устройства» кнопка «Отчёт…» сохраняет его USB-ID и список
HID-интерфейсов в файл (без серийных номеров). По отчёту можно найти протокол и добавить поддержку.

Все команды записи уходят в устройство только по кнопкам в интерфейсе.

## Обычный запуск

Ярлык **Periph Studio** на рабочем столе, или `dist\Periph Studio-win32-x64\Periph Studio.exe`.
Папку `Periph Studio-win32-x64` можно скопировать куда угодно — она самодостаточна.

Для Keydous/Royuan: клавиатура подключена кабелем (FN+5), Keydous Driver закрыт.
Для мышей Logitech: G HUB может перезаписывать DPI — лучше закрыть его.

## Сборка (PowerShell, из папки проекта)

    npm.cmd install
    npm.cmd run pack

`pack` собирает portable-папку в `dist\` и пересоздаёт ярлык на рабочем столе
(`node scripts\build.js --no-shortcut` — без ярлыка). Перед сборкой закройте приложение.

## Запуск из исходников

    npm.cmd run fix-electron
    npm.cmd start

`fix-electron` докачивает Electron в `node_modules\electron\dist`. Штатные распаковщики
(extract-zip) под Node 26 молча обрываются, поэтому `scripts\build.js` распаковывает zip
системным `tar.exe`.

## Устройство кода

- `hid.js` — Keydous/Royuan (feature reports, протокол YC200/RY108), `profiles/royuan.json` — модели.
- `kt87.js` — Winbond 0416:B23C (output reports, протокол из открытого разбора).
- `logitech.js` — HID++ 2.0 (long reports 0x11, через HIDAsync).
- `razer.js` — мыши Razer (feature reports 90 байт, протокол openrazer).
- `via.js` — QMK/VIA raw HID.
- `sonix.js` — Sonix/DriveAll (feature reports на FF13, протокол из драйвера Womier SK80, MIT).
- `tools/gen-royuan-profiles.js` — пересобрать профили из копии БД драйвера Keydous.
- `tools/kt87/` — запись и разбор USB-обмена (USBPcap) для новых протоколов.

Бэкапы раскладки NJ80: `%APPDATA%\Periph Studio\backups` (старые из `NJ80 Studio` переносятся сами).
